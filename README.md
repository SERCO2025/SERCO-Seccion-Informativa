# SERCO — Sección Informativa

Repositorio independiente para desarrollar la futura Sección Informativa de SERCO — Servicio de Construcción y Urbanización.

## Archivos iniciales

- `index.html` — sección pública de consulta y búsqueda.
- `dashboard.html` — prototipo del creador/editor de publicaciones multimedia.

## Alcance inicial

La sección contendrá información real de construcción, urbanización y pavimentación: notas, definiciones, artículos, manuales, fotografías, imágenes, videos, gráficas, tablas y otros recursos.

El editor está pensado desde el inicio para que publicaciones y recursos puedan incorporar metadata, temas, conceptos, palabras relacionadas y relaciones con otros contenidos.

La persistencia real, colaboradores, historial de actividades, biblioteca multimedia, relaciones y esquema completo de metadata se desarrollarán progresivamente antes de integrar esta sección con la página principal de SERCO.
